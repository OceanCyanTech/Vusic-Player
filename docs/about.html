About the Project & Developer

Built by an Indie Engineering Student.

Vusic Player started from a simple goal: creating a fast, modern Windows media player with deep audio routing and DSP tools—completely free of ads, subscriptions, and telemetry.

OceanCyan Tech

Hi, I'm Hemanth

Electronics & Communication Engineering (ECE) Undergraduate • Developer of Vusic Player

I'm a first-year B.Tech Electronics & Communication Engineering student at Manipal Institute of Technology (MIT Manipal), India. Alongside studying electronics, signals, and systems programming, I enjoy building native desktop software, experimenting with low-level audio pipelines, and creating 3D animation and visual art.

I created Vusic Player under OceanCyan Tech because I wanted a lightweight, native WinUI 3 media player capable of routing audio to multiple headphones or speakers simultaneously, applying live digital reverb and pitch shifts, and editing synchronized lyrics and subtitles without bloated third-party tools.

Design Principles

  • Native Windows Performance: Built with C#, .NET 8, and WinUI 3 so the interface feels responsive and at home on Windows 10 and 11.
  • Privacy by Default: Your media library, playlists, and audio DSP run locally on your machine with zero ads or tracking.
  • Open Source (GPLv3): The full source code is publicly available on GitHub for transparency, learning, and community contributions.

Under the Hood

Vusic Player combines modern Windows UI frameworks with battle-tested native multimedia engines:

WinUI 3 & Windows App SDK Flyleaf & DirectX XAudio2 Multi-Endpoint FFmpeg & SoX DSP SQLite TagLib# & LRCLIB
